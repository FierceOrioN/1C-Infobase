1C infobase that implements managment system of amusement park

1C конфигурация для автоматизации деятельности парка развлечений (разработано в рамках демонстрационного экзамена)

## Технологический стек
**Платформа** 1С:Предприятие 8.5
**Вариант развертывания:** Файловый (File)
**Режим приложения:** Управляемое приложение

## Инструкция по развертыванию
Для запуска и проверки информационной базы выполните следующие шаги:
1. Скачайте файл `Infobase.dt` из данного репозитория.
2. Откройте **1С:Предприятие — Запуск** и нажмите кнопку **Добавить**.
3. Выберите «Создание новой информационной базы» -> «Создание информационной базы без конфигурации».
4. Укажите имя базы (например, *Парк аттракционов*) и выберите пустую директорию на диске.
5. Запустите созданную базу в режиме **Конфигуратор**.
6. В верхнем меню выберите: **Администрирование** -> **Загрузить информационную базу**
7. Укажите путь к скачанному файлу `Infobase.dt`.
